# Prompt archive

Esta sección conserva instrucciones relevantes que definieron fases de Lecta. No sustituye requisitos, ADR ni documentación actual: los prompts registran intención histórica; el código, tests y documentos normativos describen el comportamiento vigente.

## Política

- No incluir API keys, credenciales o datos personales.
- Conservar prompts que expliquen una fase o auditoría relevante.
- Indicar resultado y documentos derivados cuando existan.
- No crear una página por conversación menor.
