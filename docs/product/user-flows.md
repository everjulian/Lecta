# User Flows

## Sesión

```text
Biblioteca → Nueva sesión → Grabar → Pausar/Reanudar → Finalizar
```

## Material derivado

```text
Sesión completada → Transcribir → Leer segmentos → Generar apuntes
```

## Recuperación

```text
Inicio → Detectar grabación incompleta → Recuperar o descartar explícitamente
```

## Conocimiento

```text
Biblioteca → Preguntar → Respuesta respaldada → Fuente → Audio en timestamp
```

Los errores nunca deben ocultar qué artefactos permanecen seguros.
