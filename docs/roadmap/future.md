# Future

Posibilidades sujetas a ADR y validación:

- Packaging y actualización segura para Windows.
- Backups/exportación local verificable.
- Índice vectorial especializado si los benchmarks lo justifican.
- Soporte adicional de proveedores de transcripción e IA.
- Versiones de documentación para releases relevantes.
- Observabilidad local con file logger y política de retención.

No son compromisos de release hasta tener alcance, evidencia y decisión explícita.
