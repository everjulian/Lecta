# Tokens

Los tokens actuales viven en `apps/desktop/renderer/styles.css`. Esta página documenta la intención; el CSS sigue siendo la fuente ejecutable.

| Familia       | Uso                                 |
| ------------- | ----------------------------------- |
| Primary green | Acción principal, foco y marca      |
| Surface       | Fondo, paneles y tarjetas           |
| Text          | Jerarquías de lectura               |
| Danger        | Error y acciones destructivas       |
| Spacing       | Ritmo amplio de 4/8 px              |
| Radius        | Inputs, botones, paneles y diálogos |

No copies colores manualmente a nuevos componentes si ya existe una variable adecuada.
