# Design System

Lecta usa un sistema pequeño orientado a claridad, no una librería de componentes generalista.

## Fundamentos

- Verde sobrio para acciones y estados positivos.
- Neutros cálidos para superficies.
- Tipografía del sistema para rendimiento y familiaridad.
- Radios moderados y sombras discretas.
- Estados de foco visibles y movimiento reducible.

Los valores concretos están en [Tokens](./tokens.md); el inventario funcional está en [Components](./components.md).
