# Components

| Componente         | Responsabilidad clave                             |
| ------------------ | ------------------------------------------------- |
| New Session Dialog | Captura de metadata, focus trap y Escape          |
| Session Row/Card   | Resumen navegable de una sesión                   |
| Recorder controls  | Grabar, pausar, reanudar y finalizar              |
| Tabs               | Navegación por resumen, notas, transcript y audio |
| ErrorNotice        | Qué pasó, estado seguro, retry e ID técnico       |
| Transcript Panel   | Segmentos y timestamps reproducibles              |
| Recovery Banner    | Recuperar o descartar chunks incompletos          |

Los selectores de pruebas priorizan rol, label y nombre accesible; `data-testid` es el último recurso.
