# UX Principles

- Una acción primaria por pantalla.
- Jerarquía clara y espacios amplios.
- El usuario siempre sabe si Lecta está grabando.
- La grabación nunca empieza automáticamente.
- Los estados no dependen solo del color.
- Los errores explican qué pasó, qué sigue seguro y qué puede hacer el usuario.
- Las operaciones pesadas no bloquean navegación ni grabación.

Consulta [Accessibility](../accessibility/ACCESSIBILITY.md) y [UX/UI Audit](./UX-UI-AUDIT.md).
