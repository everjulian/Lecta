# Releases

Lecta aún no mantiene releases publicadas formalmente.

## Estrategia

- `v0.1`: primera baseline funcional distribuible.
- `v0.2`: evolución compatible con notas de migración.
- `v1.0`: contrato estable de producto y datos.

Cada release relevante deberá registrar funcionalidades, correcciones, cambios de datos, limitaciones conocidas y versión congelada de documentación cuando corresponda. No se versiona documentación por commit.
