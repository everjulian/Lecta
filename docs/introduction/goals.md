# Objetivos

Lecta busca capturar conocimiento hablado sin interrumpir la actividad principal del usuario.

## Objetivos actuales

- Grabar audio del sistema y micrófono en Windows mediante una acción explícita.
- Preservar sesiones y fragmentos frente a cierres inesperados.
- Transcribir offline fuera de Electron main y renderer.
- Generar material derivado sin destruir audio ni transcripción.
- Encontrar información mediante FTS y recuperación semántica con citas.
- Mantener límites arquitectónicos verificables y una UX comprensible.

## Fuera de alcance inmediato

- Captura de video.
- Procesamiento pesado durante una grabación.
- Sincronización cloud obligatoria.
- Respuestas sin evidencia local suficiente.
