# Lecta

Lecta es una aplicación desktop local-first para registrar clases y reuniones, conservar el audio en fragmentos recuperables y producir artefactos derivados: transcripciones, apuntes estructurados y respuestas respaldadas por fuentes locales.

La documentación está dirigida a desarrollo, QA, producto, diseño y futuras personas colaboradoras. Describe el sistema que existe hoy; no es material de marketing ni una promesa de funcionalidades futuras.

## Cadena de valor

```text
Sesión → Grabación → Transcripción → Apuntes → Recuperación de conocimiento
```

Cada nivel conserva al anterior. Regenerar apuntes no modifica la transcripción; transcribir no modifica el audio.
